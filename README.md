# Absolute Optimizer

Переносимый игровой оптимизатор для Windows 10 22H2 и Windows 11 x64. Интерфейс на русском языке. Для запуска готовой сборки Node.js не требуется.

## Запуск

Распакуйте **AbsoluteOptimizer-win-x64.zip** целиком и запустите **AbsoluteOptimizer.exe** из распакованной папки. Остальные файлы в папке нужны для запуска. Сборка без цифровой подписи.

## Производительность

1. На вкладке **Обзор** нажмите **Включить профиль**. Приложение выключит фоновую запись Xbox Game Bar для текущего пользователя и переключится на схему высокой производительности, если Windows её предоставляет.
2. Перезапустите игру, чтобы она подхватила настройки записи. Для временного повышения приоритета откройте **Производительность**, нажмите **Обновить**, выберите окно игры и нажмите **Повысить приоритет**.
3. Чтобы отменить изменения, нажмите **Вернуть настройки** или **Вернуть приоритет**. Схема питания и настройки записи сохраняются после закрытия оптимизатора. Приоритет процесса сбрасывается при выходе из игры.

Замерьте FPS встроенным счётчиком игры в одной и той же сцене с одинаковыми настройками. Изменение зависит от игры, фоновой нагрузки и железа. Высокая производительность может повысить расход батареи. Для некоторых игр и процессов изменение приоритета ограничивает Windows.

## Сеть

1. Укажите IP-адрес или имя хоста, который отвечает на ICMP. Адрес по умолчанию — публичный узел Cloudflare `1.1.1.1`. Он показывает задержку до этого узла. Для игрового маршрута укажите доступный IP сервера игры.
2. Запустите тест и сохраните результат как «до». Программа измеряет 12 запросов, среднюю задержку, среднюю разницу между соседними ответами и долю запросов без ответа.
3. Если фоновая отправка данных перегружает канал, выберите исполняемый файл фонового приложения и задайте предел в Мбит/с. Подтвердите запрос Windows на права администратора. Правило QoS относится к исходящему трафику выбранного приложения. Доступность зависит от модуля NetQos и конфигурации Windows.
4. Повторите тест при той же нагрузке и на том же IP. Снимите лимит в интерфейсе или перезагрузите Windows. QoS снижает задержку только если ограниченная фоновая отдача создавала очередь на исходящем канале.

## Исходный код и сборка

Нужны Node.js 22.12+ и npm. На Windows выполните:

```powershell
npm ci
npm test
npm start
```

Команда `npm run pack:win` собирает папку `dist/AbsoluteOptimizer-win-x64` с исполняемым файлом, значком и средой Electron. Сборщик скачивает официальный архив Electron и сверяет SHA-256. Также можно передать путь к ранее скачанному архиву командой `npm run pack:win -- C:\путь\к\electron.zip`. Чтобы отправить сборку, упакуйте в ZIP всю папку.

Параметры для восстановления хранятся в `%APPDATA%\Absolute Optimizer\restore.json`. Все интерфейсные ресурсы включены в приложение. Шрифт Golos Text поставляется по лицензии SIL Open Font License в папке `app/ui/fonts`.
